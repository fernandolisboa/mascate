Credenciais do Mascate

O passo a passo de cada plataforma, com que nome o app espera cada valor e onde colar. Clique num nome de variável para copiar.

Como funciona
  • No app, tudo é colado em Configurações → Conexões, e cada conexão tem Como conseguir as chaves, com estes mesmos passos e os links. O app guarda no cofre do sistema (Gerenciador de Credenciais do Windows), nunca no banco nem no Backup.
  • Variáveis de ambiente com esses nomes servem só em build de desenvolvimento (cargo run), onde têm precedência sobre o cofre; build de release as ignora. Se usar um arquivo .env, carregue-o no shell: ele nunca vai para o Git.
  • Só para desenvolvimento, MASCATE_ML_API_URL aponta o app para um servidor falso do Mercado Livre (por exemplo, um que sirva os fixtures de crates/integrations/tests/fixtures/mercado-livre); não é segredo, e build de release o ignora. Com um refresh token em variável de ambiente, lembre que o Mercado Livre o troca a cada renovação: o novo vai para o cofre e a variável fica velha.
  • Do mesmo jeito, MASCATE_SHOPEE_API_URL aponta a busca da Shopee para um servidor falso (o endereço completo do GraphQL, como http://127.0.0.1:8080/graphql, servindo os fixtures de crates/integrations/tests/fixtures/shopee-affiliate); só em build de desenvolvimento.
  • E MASCATE_ANTHROPIC_API_URL aponta o texto com IA do rascunho para um servidor falso da API da Anthropic (o endereço base, como http://127.0.0.1:8090, que recebe /v1/messages e pode servir os fixtures de crates/integrations/tests/fixtures/anthropic); só em build de desenvolvimento, para testar sem chamada paga.
  • Plataformas com login (OAuth) pedem só o par do app; os tokens de acesso o próprio app obtém e renova quando você clica em Conectar.

Fase 1 venda no ML e descoberta

Mercado Livre

criar agora

Conta de vendedor: anúncios, pedidos e estoque.

  1. Entre no DevCenter do Mercado Livre com a mesma conta em que você vende. Abrir o DevCenter
  2. Crie uma aplicação nova: nome, nome curto, descrição de até 150 caracteres e um logotipo.
  3. Em URI de redirect, o Mercado Livre exige um endereço https. Enquanto o botão Conectar não chega, cadastre https://github.com/fernandolisboa; o app vai mostrar o endereço definitivo, e você troca na mesma aplicação.
  4. Nos escopos, marque leitura, escrita e acesso offline: com o acesso offline o app renova o login sozinho. Os tópicos de notificação podem ficar vazios, porque o app busca as mudanças por conta própria.
  5. Salve e abra a aplicação na lista do DevCenter. Copie o App ID, que é o Client ID, e a Secret Key, que é o Client Secret.
  6. No app, abra Configurações → Conexões → Mercado Livre → Como conseguir as chaves, cole e clique em Salvar.

Depois de salvar, falta entrar na sua conta de vendedor pelo botão Conectar, que chega numa próxima versão.

Variáveis

Shopee Afiliados

pedir acesso

Open API de afiliados: busca de ofertas. Sem credenciais, fica aguardando aprovação e a descoberta usa o cadastro manual de ofertas.

  1. Entre no portal de afiliados da Shopee com a sua conta de afiliado. Quem ainda não é afiliado se cadastra no mesmo portal. Abrir o portal de afiliados
  2. Abra a área Open API e peça acesso. A Shopee aprova à mão e pode levar semanas; até lá, a descoberta usa o cadastro manual de ofertas. Abrir a Open API
  3. Com o acesso aprovado, a mesma página mostra o AppID, um número longo, e o Secret. Copie os dois. O PID de afiliado não é o AppID: se a página só mostra o PID, o acesso ainda não foi liberado.
  4. No app, abra Configurações → Conexões → Shopee Afiliados → Como conseguir as chaves, cole e clique em Salvar.
Variáveis

Anthropic

criar agora

Títulos e descrições de anúncio gerados como rascunho.

  1. Entre no Claude Console, o antigo console da Anthropic, ou crie uma conta. Abrir o Claude Console
  2. Em Settings, Billing, clique em Buy credits e escolha um valor. A API cobra por uso e, sem saldo, o texto com IA falha. Os créditos valem por um ano. Abrir Billing
  3. Em Settings, API keys, clique em Create key, dê um nome como Mascate, escolha a validade e deixe Linked account na sua conta. Abrir API keys
  4. Copie a chave, que começa com sk-ant-. O Console só mostra a chave inteira nessa hora; se perder, crie outra.
  5. No app, abra Configurações → Conexões → Anthropic → Como conseguir as chaves, cole e clique em Salvar.
