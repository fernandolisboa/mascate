Credenciais do Mascate

O passo a passo de cada plataforma, com que nome o app espera cada valor e onde colar. Clique num nome de variável para copiar.

Como funciona
  • No app, tudo é colado em Configurações → Conexões, e cada conexão tem Como conseguir as chaves, com estes mesmos passos e os links. O app guarda no cofre do sistema (Gerenciador de Credenciais do Windows), nunca no banco nem no Backup.
  • Variáveis de ambiente com esses nomes servem só em build de desenvolvimento (cargo run), onde têm precedência sobre o cofre; build de release as ignora. Se usar um arquivo .env, carregue-o no shell: ele nunca vai para o Git.
  • Só para desenvolvimento, MASCATE_ML_API_URL aponta o app para um servidor falso do Mercado Livre (por exemplo, um que sirva os fixtures de crates/integrations/tests/fixtures/mercado-livre); não é segredo, e build de release o ignora. Com um refresh token em variável de ambiente, lembre que o Mercado Livre o troca a cada renovação: o novo vai para o cofre e a variável fica velha.
  • Do mesmo jeito, MASCATE_SHOPEE_API_URL aponta a busca da Shopee para um servidor falso (o endereço completo do GraphQL, como http://127.0.0.1:8080/graphql, servindo os fixtures de crates/integrations/tests/fixtures/shopee-affiliate); só em build de desenvolvimento.
  • Para as comissões da Hotmart, MASCATE_HOTMART_API_URL aponta o pedido de token e as vendas para um servidor falso (o endereço base, como http://127.0.0.1:8095, que recebe /security/oauth/token e /payments/api/v1/sales/… e pode servir os fixtures de crates/integrations/tests/fixtures/hotmart); só em build de desenvolvimento.
  • Para as comissões da Monetizze, MASCATE_MONETIZZE_API_URL aponta o pedido de token e as vendas para um servidor falso (o endereço base, como http://127.0.0.1:8097, que recebe /token e /transactions e pode servir os fixtures de crates/integrations/tests/fixtures/monetizze); só em build de desenvolvimento.
  • Para as comissões e os saques da Kiwify, MASCATE_KIWIFY_API_URL aponta o pedido de token, as vendas e os saques para um servidor falso (o endereço base, como http://127.0.0.1:8098, que recebe /v1/oauth/token, /v1/sales e /v1/payouts e pode servir os fixtures de crates/integrations/tests/fixtures/kiwify); só em build de desenvolvimento.
  • Para as comissões e as transferências da Eduzz, MASCATE_EDUZZ_API_URL aponta o extrato, as vendas e as transferências para um servidor falso (o endereço base, como http://127.0.0.1:8099, que recebe /myeduzz/v2/financial/statement, /myeduzz/v1/sales e /myeduzz/v1/financial/transfers e pode servir os fixtures de crates/integrations/tests/fixtures/eduzz); só em build de desenvolvimento.
  • Para publicar no Telegram, MASCATE_TELEGRAM_API_URL aponta "Conferir canal" e "Publicar agora" para um servidor falso da Bot API (o endereço base, como http://127.0.0.1:8096, que recebe /bot<token>/getMe, getChat, getChatMember, sendMessage e sendPhoto e pode servir os fixtures de crates/integrations/tests/fixtures/telegram); só em build de desenvolvimento, para testar sem postar num canal de verdade. O chat do canal não é credencial: fica em cada canal de divulgação.
  • Para o crawler do Mercado Livre (desligado até você ligar a flag em Configurações → Funcionalidades restritas), MASCATE_MERCADO_LIVRE_LISTING_URL aponta a busca para um servidor falso (o endereço base, como http://127.0.0.1:8093, que recebe /robots.txt e /{palavras-com-traços} e pode servir os fixtures de crates/integrations/tests/fixtures/mercado-livre-crawler); só em build de desenvolvimento. O crawler não usa credencial.
  • Para vender na Amazon, MASCATE_AMAZON_API_URL aponta o pedido de token, os anúncios, os pedidos, as tarifas e a confirmação de envio para um servidor falso (o endereço base, como http://127.0.0.1:8094, que recebe /auth/o2/token, /listings/2021-08-01/items/…, /definitions/2020-09-01/productTypes/…, /products/fees/v0/listings/…/feesEstimate, /orders/2026-01-01/orders…, /finances/2024-06-19/transactions e /orders/v0/orders/…/shipmentConfirmation e pode servir os fixtures de crates/integrations/tests/fixtures/amazon-seller); só em build de desenvolvimento. O refresh token da Amazon não muda a cada renovação, então a variável continua valendo.
  • Para vender na Shopee, MASCATE_SHOPEE_SELLER_API_URL aponta o login, os anúncios, o estoque e o preço da Shopee de vendedor para outro endereço base: o sandbox da Shopee (https://openplatform.sandbox.test-stable.shopee.sg, com as chaves de teste do app) ou um servidor falso (como http://127.0.0.1:8093, que recebe /api/v2/auth/… e /api/v2/product/… e pode servir os fixtures de crates/integrations/tests/fixtures/shopee-seller); só em build de desenvolvimento. A Shopee troca o refresh token a cada renovação, como o Mercado Livre: com ele em variável de ambiente, o novo vai para o cofre e a variável fica velha.
  • Para vender na Magalu, MASCATE_MAGALU_API_URL aponta a Open API para outro endereço base: o sandbox da Magalu (https://api-sandbox.magalu.com, com o login no ID Magalu de sempre) ou um servidor falso (como http://127.0.0.1:8095, que recebe também o login, /oauth/token, e /seller/v1/portfolios/…, e pode servir os fixtures de crates/integrations/tests/fixtures/magalu); só em build de desenvolvimento. O app trata o refresh token da Magalu como de uso único: com ele em variável de ambiente, o novo vai para o cofre e a variável fica velha.
  • E MASCATE_ANTHROPIC_API_URL aponta o texto com IA do rascunho para um servidor falso da API da Anthropic (o endereço base, como http://127.0.0.1:8090, que recebe /v1/messages e pode servir os fixtures de crates/integrations/tests/fixtures/anthropic); só em build de desenvolvimento, para testar sem chamada paga.
  • Plataformas com login (OAuth) pedem só o par do app; os tokens de acesso o próprio app obtém e renova quando você clica em Conectar.

Fase 1 venda no ML e descoberta

Mercado Livre

criar agora

Conta de vendedor: anúncios, pedidos e estoque.

  1. Entre no DevCenter do Mercado Livre com a mesma conta em que você vende. Abrir o DevCenter
  2. Crie uma aplicação nova: nome, nome curto, descrição de até 150 caracteres e um logotipo.
  3. Em URI de redirect, o Mercado Livre exige um endereço https. Enquanto o botão Conectar não chega, cadastre https://github.com/fernandolisboa; o app vai mostrar o endereço definitivo, e você troca na mesma aplicação.
  4. Nos escopos, marque leitura, escrita e acesso offline: com o acesso offline o app renova o login sozinho. Os tópicos de notificação podem ficar vazios, porque o app busca as mudanças por conta própria.
  5. Salve e abra a aplicação na lista do DevCenter. Copie o App ID, que é o Client ID, e a Secret Key, que é o Client Secret.
  6. No app, abra Configurações → Conexões → Mercado Livre → Como conseguir as chaves, cole e clique em Salvar.

Depois de salvar, falta entrar na sua conta de vendedor pelo botão Conectar, que chega numa próxima versão.

Shopee Afiliados

pedir acesso

Open API de afiliados: busca de ofertas. Sem credenciais, fica aguardando aprovação e a descoberta usa o cadastro manual de ofertas.

  1. Entre no portal de afiliados da Shopee com a sua conta de afiliado. Quem ainda não é afiliado se cadastra no mesmo portal. Abrir o portal de afiliados
  2. Abra a área Open API e peça acesso. A Shopee aprova à mão e pode levar semanas; até lá, a descoberta usa o cadastro manual de ofertas, as comissões da Shopee entram à mão em Afiliação e os links curtos da Shopee esperam. Abrir a Open API
  3. Com o acesso aprovado, a mesma página mostra o AppID, um número longo, e o Secret. Copie os dois. O PID de afiliado não é o AppID: se a página só mostra o PID, o acesso ainda não foi liberado.
  4. No app, abra Configurações → Conexões → Shopee Afiliados → Como conseguir as chaves, cole e clique em Salvar.

Anthropic

criar agora

Títulos e descrições de anúncio gerados como rascunho.

  1. Entre no Claude Console, o antigo console da Anthropic, ou crie uma conta. Abrir o Claude Console
  2. Em Settings, Billing, clique em Buy credits e escolha um valor. A API cobra por uso e, sem saldo, o texto com IA falha. Os créditos valem por um ano. Abrir Billing

  5. No app, abra Configurações → Conexões → Anthropic → Como conseguir as chaves, cole e clique em Salvar.

Fase 2 afiliação e divulgação

Hotmart

criar agora

Comissões de afiliado: vendas, status, estornos e cancelamentos, lidos a cada hora.

  1. Entre na Hotmart com a sua conta e abra Ferramentas, Credenciais Developers. Abrir Credenciais Developers
  2. Clique em Criar credencial e dê um nome como Mascate. Deixe o tipo sandbox desmarcado: a credencial de sandbox só enxerga vendas de teste.
  3. Confirme. A Hotmart mostra o Client ID, o Client Secret e o Basic; copie os três antes de fechar. Se perder algum, apague a credencial e crie outra.
  4. No app, abra Configurações → Conexões → Hotmart → Como conseguir as chaves, cole e clique em Salvar.

Monetizze

criar agora

Comissões de afiliado: vendas, status, estornos e cancelamentos, lidos a cada hora.

  1. Entre na Monetizze com a sua conta de afiliado e abra Ferramentas, API no menu. Abrir a Monetizze
  2. Crie uma chave de acesso e dê um nome como Mascate. Se a Monetizze pedir as permissões, marque a consulta de transações: o app só lê as vendas.

Eduzz

criar agora

Comissões de afiliado e transferências: extrato, vendas, estornos e chargebacks, lidos a cada hora.

  1. Entre no console de desenvolvedor da Eduzz com a sua conta e abra Meus Aplicativos. Abrir o console da Eduzz

Telegram

criar agora

Bot que publica os posts de oferta nos seus canais do Telegram, sempre depois da sua confirmação.

  1. No Telegram, abra o BotFather, o bot oficial que cria bots. Abrir o BotFather
  2. Mande /newbot, escolha um nome (como Mascate Ofertas) e um nome de usuário que termine em bot. O BotFather responde com o token, um texto como 123456789:AAH…; copie-o inteiro. Quem tem o token posta pelo bot: não mande para ninguém.
  3. No seu canal, abra Administradores, Adicionar administrador, busque o bot pelo nome de usuário e deixe ligada a permissão Publicar mensagens. Repita em cada canal onde o app vai postar.
  4. No app, abra Configurações → Conexões → Telegram → Como conseguir as chaves, cole e clique em Salvar.

Depois de salvar, informe o @nome do canal (ou o id -100… de um canal privado) em Divulgação e use Conferir canal: o app confirma que o bot é administrador e pode publicar.

Fase 3 novos canais

Amazon

criar agora

Conta de vendedor na Amazon.com.br: anúncios, estoque e preço, pela Selling Partner API.

  1. No Seller Central da Amazon.com.br, confira em Configurações › Informações da conta que a conta está no plano Profissional: o plano Individual não usa a API. Entre como usuário principal da conta, o único que autoriza apps.
  2. Abra Apps e serviços › Desenvolver apps e preencha o perfil de desenvolvedor como desenvolvedor privado, para uso só na própria conta. Marque os papéis Product Listing, Pricing e Inventory and Order Tracking; peça também Direct-to-Consumer Shipping, o papel restrito que libera o endereço do comprador para os pedidos e passa por análise da Amazon. Abrir Desenvolver apps
  3. Com o perfil aprovado, clique em Adicionar novo cliente de app, dê um nome como Mascate, escolha SP API e os mesmos papéis. Em Credenciais LWA, clique em Visualizar e copie o Client ID e o Client Secret. Ver os papéis da API
  4. Na linha do app, abra Autorizar e clique em Autorizar app: a Amazon mostra o refresh token uma vez só. Copie inteiro; se perder, autorize de novo e cole o novo. Como autorizar o próprio app
  5. Em Configurações › Informações da conta › Seu token de comerciante, copie o ID de vendedor (o Merchant Token, como A1B2C3D4E5F6G7). Abrir o token de comerciante
  6. No app, abra Configurações → Conexões → Amazon → Como conseguir as chaves, cole e clique em Salvar.

O Client Secret vence a cada 180 dias: a Amazon avisa antes, e o app lembra em Lembretes. Gere um novo na mesma tela de credenciais e cole aqui só o Client Secret; o resto continua valendo.

Variáveis

Shopee (vendedor)

criar agora

Loja de vendedor na Shopee: anúncios, estoque e preço, pela Open Platform. São outra API e outras chaves que as da Shopee Afiliados.

  1. A Shopee pede CNPJ para registrar um app de vendedor na Open Platform: o cadastro de vendedor individual não abre no Brasil. Sem CNPJ, os passos abaixo esperam, e o app lembra disso em Lembretes. Abrir a Open Platform
  2. Entre no console da Open Platform, cadastre-se como desenvolvedor do tipo Seller In House System e crie um app para a sua loja. Abrir o console
  3. No app, em Redirect URL Domain, cadastre https://github.com/fernandolisboa: depois do login, a Shopee manda o navegador para lá com o código que você cola no Mascate.
  4. Peça a publicação do app (Go Live). Aprovado, copie o Live Partner ID, um número, e a Live Partner Key. As chaves de teste só valem no sandbox da Shopee.
  5. No app, abra Configurações → Conexões → Shopee (vendedor) → Como conseguir as chaves, cole e clique em Salvar.

Depois de salvar, clique em Entrar na Shopee, autorize o app com a conta da loja e cole o endereço em que o navegador parou. A autorização da loja vale até um ano; quando vencer, entre de novo do mesmo jeito.

Variáveis

Magalu

criar agora

Loja de vendedor na Magalu: SKUs, estoque e preço, pela Open API da Magalu.

  1. A Magalu vende só por loja de pessoa jurídica: o cadastro do Parceiro Magalu pede CNPJ. Sem ele, os passos abaixo esperam, e o app lembra disso em Lembretes. Abrir o portal de desenvolvedores
  2. Baixe o ID Magalu CLI para o seu sistema, renomeie o arquivo para idm e, no Windows, mova para C:\Windows\System32. No terminal, rode idm login, entre com a conta da loja e autorize Criar client e Atualizar client. Baixar o idm
  3. Crie o cliente do app com: idm client create --name "Mascate" --description "Gestão da loja" --terms-of-use "https://github.com/fernandolisboa/mascate" --privacy-term "https://github.com/fernandolisboa/mascate" --redirect-uris "https://github.com/fernandolisboa" --audience "https://api.magalu.com https://services.magalu.com" --scopes "open:portfolio-skus-seller:read open:portfolio-prices-seller:read open:portfolio-prices-seller:write open:portfolio-stocks-seller:read open:portfolio-stocks-seller:write open:order-order-seller:read open:order-delivery-seller:read open:order-financial-report-seller:read" --access-token-exp 7200
  4. Copie o Client ID e o Client Secret que o idm mostra: o Client Secret não aparece de novo; se perder, crie outro cliente.
  5. No app, abra Configurações → Conexões → Magalu → Como conseguir as chaves, cole e clique em Salvar.

Depois de salvar, clique em Entrar na Magalu, entre com o ID Magalu, escolha a loja, autorize o app e cole o endereço em que o navegador parou. O app renova o login sozinho; se a Magalu deixar de aceitar, entre de novo do mesmo jeito.
