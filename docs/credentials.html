Credenciais do Mascate

O que criar em cada plataforma, com que nome o app espera cada valor e onde colar. Clique num nome de variável para copiar.

Como funciona
  • No app, tudo é colado em Configurações → Conexões. O app guarda no cofre do sistema (Gerenciador de Credenciais do Windows), nunca no banco nem no Backup.
  • Variáveis de ambiente com esses nomes servem só em build de desenvolvimento (cargo run), onde têm precedência sobre o cofre; build de release as ignora. Se usar um arquivo .env, carregue-o no shell: ele nunca vai para o Git.
  • Só para desenvolvimento, MASCATE_ML_API_URL aponta o app para um servidor falso do Mercado Livre (por exemplo, um que sirva os fixtures de crates/integrations/tests/fixtures/mercado-livre); não é segredo, e build de release o ignora. Com um refresh token em variável de ambiente, lembre que o Mercado Livre o troca a cada renovação: o novo vai para o cofre e a variável fica velha.
  • Plataformas com login (OAuth) pedem só o par do app; os tokens de acesso o próprio app obtém e renova quando você clica em Conectar.

Fase 1 venda no ML e descoberta

Mercado Livre (vendedor)

criar agora
Onde criar
DevCenter do Mercado Livre → Criar aplicação. A URL de redirecionamento a cadastrar aparece na tela de conexão do app.
Variáveis
Depois
Conexões → Mercado Livre → Conectar, e fazer login na sua conta de vendedor.

Shopee Afiliados (Open API)

pedir acesso
Onde criar
Portal de afiliados da Shopee → Open API → solicitar acesso. A aprovação pode levar semanas; até lá o app usa cadastro manual de ofertas.
Variáveis
Depois
Conexões → Shopee Afiliados → colar AppID e Secret.

Anthropic (títulos e descrições de anúncio)

criar agora
Onde criar
Console da Anthropic → API Keys → Create Key. Cobrança por uso.
Variáveis
Depois
Conexões → Anthropic → colar a chave.
